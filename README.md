# 🐰 ร้านน้องนิดา 2.0 (Nida's Sweet Shop)

เว็บแอปโต้ตอบบทบาทสมมติ (Pretend Play) ร้านค้าแสนน่ารัก ออกแบบมาสำหรับเล่นกับลูกสาววัย 4–5 ขวบ ใช้งานได้จริงทั้ง **Online** และ **Offline 100%** รองรับการติดตั้งเป็นแอปเต็มจอ (PWA) บน iPad, แท็บเล็ต Android, มือถือ และคอมพิวเตอร์

---

## 🌟 ฟีเจอร์เด่น (Features)

1. **🎨 ตัวละครสลับได้ 2 สไตล์ (Character Switcher)**
   * **น้องขยับได้ (Articulated Rig)**: หูกระดิกได้ ตาเปลี่ยนอารมณ์ ปากขยับลิปซิงก์ตามเสียงพูด แขนโบกทักทาย/คิดเงินได้
   * **น้อง 3D (3D Fluffy Bunny)**: รูปกระต่าย 3D ขนปุกปุยนุ่มนิ่ม น่ารัก สดใส
2. **🛒 เล่นขายของ (Market Mode)**: สินค้า 8 ชิ้น แตะสแกนบาร์โค้ดมีเสียง "ติ๊ด!" ของลอยเข้าตะกร้า มีปุ่มคิดเงิน "กริ๊งงง!" พร้อมพลุกระดาษ Confetti ฉลองเต็มจอ
3. **🥕 ป้อนขนมน้อง (Feed Mode)**: แตะป้อนแครอท เค้ก ผลไม้ ของจะบินไปที่ปากกระต่ายพร้อมเสียงเคี้ยว "ง่ำ ๆ"
4. **💬 ชวนคุยบทบาทสมมติ (Roleplay 1–4)**: ต้อนรับ 👋, รับอะไรดี 💬, บอกราคา 🏷️, ขอบคุณ 💖 (กดเลข 1–4 บนคีย์บอร์ดได้)
5. **🥰 อารมณ์และการมีส่วนร่วม**: ดีใจ, หัวเราะ, ตกใจ, ง่วงนอน, เต้นระบำ 💃, ชมคนเก่ง 🌟 และแตะพุงจั๊กจี้
6. **🔊 เสียงเอฟเฟกต์ Offline 100% (Web Audio API)**: สังเคราะห์เสียงในเครื่อง ไม่ต้องโหลดไฟล์ MP3 ภายนอก ไร้ปัญหาเน็ตหลุด
7. **📱 PWA & Fullscreen**: ติดตั้งเป็นไอคอนบนหน้าจอโฮม เล่นเต็มจอไร้แถบเบราว์เซอร์

## 🚀 วิธีนำขึ้น GitHub & เปิดใช้งาน GitHub Pages ฟรี

### ขั้นตอนที่ 1: เตรียม Git บนเครื่องคอมพิวเตอร์
เปิด Terminal / PowerShell ในโฟลเดอร์นี้ แล้วรันคำสั่ง:

```bash
git init
git add .
git commit -m "feat: Nida Shop v2.0 with PWA and switchable characters"
git branch -M main
```

### ขั้นตอนที่ 2: เชื่อมต่อไปยัง GitHub Repository
สร้าง Repository ใหม่บน [GitHub.com](https://github.com) (ตั้งชื่อเช่น `Nida_shop`) แล้วรันคำสั่ง:

```bash
git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
git push -u origin main
```

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages
1. เข้าไปที่หน้า Repository บน GitHub
2. ไปที่แท็บ **Settings** ➡️ เมนูด้านซ้ายเลือก **Pages**
3. ตรงหัวข้อ **Branch** ให้เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1–2 นาที จะได้รับลิงก์เว็บ เช่น `https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/`

## 📲 วิธีติดตั้งลง iPad / iPhone / Android

* **iPad / iPhone (Safari)**: เปิดลิงก์เว็บ ➡️ กดปุ่มแชร์ (Share) ➡️ เลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
* **Android (Chrome)**: เปิดลิงก์เว็บ ➡️ แตะแถบสีชมพู **"ติดตั้ง"** หรือกดเมนู 3 จุด ➡️ **"ติดตั้งแอป"**
