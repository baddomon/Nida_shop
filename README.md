# 🐰 ร้านน้องนิดา 3.2 (Nida's Sweet Shop - Bilingual Edition)

เว็บแอปโต้ตอบบทบาทสมมติ (Pretend Play) ร้านค้าแสนน่ารักสำหรับเด็กวัย 4–5 ขวบ รองรับ **2 ภาษา (🇹🇭 ไทย - 🇬🇧 อังกฤษ)** ในตัว พร้อมเสียงพูดสำเนียงเด็กน่ารัก ใช้งานได้จริงทั้ง **Online** และ **Offline 100%** รองรับการติดตั้งเป็นแอปเต็มจอ (PWA) บน iPad, แท็บเล็ต Android, มือถือ และคอมพิวเตอร์

---

## 🌟 ฟีเจอร์เด่น (Features)

1. **🌐 ระบบสลับ 2 ภาษา (Bilingual Mode 🇹🇭 / 🇬🇧 - v3.2)**
   * สลับระหว่าง **ไทย** และ **อังกฤษ** ได้ทันทีผ่านปุ่มบนแถบด้านบน
   * เสียงอ่านชื่อสินค้า, บทสนทนาบทบาทสมมติ, และเสียงพากย์น้องกระต่ายเป็นภาษาอังกฤษ (สำเนียงเด็กสดใสน่ารัก) เหมาะสำหรับฝึกคำศัพท์
   * บอลลูนและการนับเลขสลับเป็นภาษาอังกฤษ ("One", "Two", "Three"...)
2. **⚖️ เครื่องชั่งน้ำหนักผลไม้ดิจิทัล (Digital Fruit Scale - v3.1)**
   * หน้าต่างเครื่องชั่งดิจิทัลพร้อมแอนิเมชันสปริงดึ๋งดั๋ง คำนวณน้ำหนักและราคาตามจริง
   * เสียง "ติ๊ดๆ" ของเครื่องชั่งดิจิทัล และปุ่มพิมพ์ป้ายราคาใส่ตะกร้า
3. **💵 ลิ้นชักแคชเชียร์สมจริง (Cash Register Drawer - v3.1)**
   * สไลด์เปิดพร้อมเสียงกระดิ่ง "กริ๊งงง!" และเสียงเลื่อนลิ้นชัก
   * ธนบัตร 20, 50, 100, 500฿ และเหรียญ 1, 2, 5, 10฿ พร้อมระบบแนะนำเมื่อเงินไม่พอ
4. **🎯 ภารกิจน้องกระต่าย (Shopping Quest - v3.1)**
   * น้องกระต่ายขอให้ช่วยหาของ 2 ชิ้น มีชิปสถานะติ๊กถูก และให้ดาวโบนัส +2 ดวง
5. **🛒 จัดการของในตะกร้า (Basket Manager - v3.1)**
   * แตะดูรายการของในตะกร้า ลบชิ้นที่หยิบผิดออกได้ทีละชิ้น
6. **🧾 เครื่องพิมพ์ใบเสร็จความร้อน (Thermal Receipt - v3.0)**
   * จำลองเสียงและแอนิเมชันพิมพ์ใบเสร็จกระดาษ พร้อมลูกเล่นฉีกใบเสร็จ
7. **🎁 ตู้หมุนไข่กาชาปอง & 🌟 สมุดสะสมสติกเกอร์ (v3.0)**
   * หมุนตู้ไข่ลุ้นรับของขวัญ และสมุดสะสมสติกเกอร์ 12 ช่อง
8. **🎨 สลับตัวละคร 2 สไตล์ (Character Switcher)**
   * **น้องขยับได้ (Articulated Rig)**: หูกระดิก ตาเปลี่ยนอารมณ์ ปากขยับตามเสียงพูด
   * **น้อง 3D (3D Fluffy Bunny)**: รูปกระต่าย 3D ปุกปุย
9. **🥕 ป้อนขนมน้อง (Feed Mode)**: เสียงเคี้ยวกรุบกรอบ "ง่ำ ๆ" สังเคราะห์จาก Web Audio API
10. **💬 บทบาทสมมติ 1–4**: ต้อนรับ 👋, รับอะไรดี 💬, บอกราคา 🏷️, ขอบคุณ 💖
11. **🔊 เสียงเอฟเฟกต์ Offline 100% (Web Audio API)**: สังเคราะห์เสียงทั้งหมดในเครื่อง 0 KB ไฟล์เสียง
12. **📱 PWA & Fullscreen**: ติดตั้งเป็นไอคอนบนหน้าจอโฮม เล่นเต็มจอได้ 100% แม้ไม่มีอินเทอร์เน็ต

## 🚀 วิธีนำขึ้น GitHub & เปิดใช้งาน GitHub Pages ฟรี

### ขั้นตอนที่ 1: เตรียม Git บนเครื่องคอมพิวเตอร์
เปิด Terminal / PowerShell ในโฟลเดอร์นี้ แล้วรันคำสั่ง:

```bash
git init
git add .
git commit -m "feat: Nida Shop v2.0 with PWA and switchable characters"
git branch -M main
```

### ขั้นตอนที่ 2: เชื่อมต่อไปยัง GitHub Repository
สร้าง Repository ใหม่บน [GitHub.com](https://github.com) (ตั้งชื่อเช่น `Nida_shop`) แล้วรันคำสั่ง:

```bash
git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
git push -u origin main
```

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages
1. เข้าไปที่หน้า Repository บน GitHub
2. ไปที่แท็บ **Settings** ➡️ เมนูด้านซ้ายเลือก **Pages**
3. ตรงหัวข้อ **Branch** ให้เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1–2 นาที จะได้รับลิงก์เว็บ เช่น `https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/`
